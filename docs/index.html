3つのキューブが組み合わさって、新しい滞在の形をつくる。神楽坂と浅草、東京の2つのエリアでホテルを運営しています。

ABOUT / 私たちについて

株式会社スリーキューブは、旅館業に基づくホテル運営会社です。施設運営、運営代行・コンサルティング、不動産の賃貸・管理まで、宿泊を中心に事業を展開しています。エリアの個性を生かした施設づくりと、データに基づく運営で、ゲストとオーナーの双方に価値を提供します。

ご予約は各予約サイトおよびお問い合わせにて承ります。宿泊料金は施設・日程・人数により異なり、ご予約時に税込総額を表示します。
